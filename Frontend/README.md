# React + TypeScript + Vite Portfolio

This is a personal **portfolio website** built using React, TypeScript, and Vite. It showcases my skills, projects, and experience as a frontend developer.

The project is optimized for fast performance, responsive design, and modern UI/UX.

---

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- TailwindCSS / CSS
- React Router DOM
- EmailJS (for contact form)
- React Hot Toast (notifications)

---

## ⚡ Features

- 🧑 About section with personal introduction
- 💼 Projects showcase
- 🛠 Skills section
- 📬 Contact form with EmailJS integration
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🔔 Toast notifications for user feedback
